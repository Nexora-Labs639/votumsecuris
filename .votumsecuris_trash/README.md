# VotumSecuris

> **Agent 时代的安全内核**
> 本地优先 · 开箱即用 · 安全可控

---

## 一句话介绍

**VotumSecuris** 是给 AI Agent 做安全管控的本地系统。

给 AI 装方向盘和刹车——**策略引擎、审计日志、Saga 回滚、通用 RAG、多端共享记忆**。

**本地优先。开箱即用。断网能跑。**

---

## 核心能力

| 模块 | 功能 |
|---|---|
| **策略引擎** | 判断每个动作能不能执行（允许 / 拒绝 / 需要审批） |
| **审计日志** | 所有动作写入 SQLite，可查、可追溯 |
| **Saga 回滚** | 执行到第 N 步失败，自动撤销前 N-1 步 |
| **安全删除** | 删除前备份到回收站，可恢复 |
| **审批门** | 高风险操作弹窗，人工确认后才能执行 |
| **空闲态守则** | AI 无任务时保持正念、自我检查 |
| **诚实性检查** | AI 输出「保证/绝对」时自动改写或拦截 |
| **错误档案** | AI 每次犯错写进档案，下次避开 |
| **通用 RAG** | 任意知识文件放进 `knowledge/`，自动索引、检索 |
| **知识库版本化** | 每次索引生成版本，可回滚 |
| **推理引擎控制** | 4 个预设：`fast` / `balanced` / `deep` / `creative` |
| **性能观测** | 每次推理记录耗时、模型、参数 |
| **局域网同步** | 多台设备在同一 WiFi 下共享记忆，不走云 |
| **跨端 UI** | Flutter 一套代码，桌面 + 安卓 + iOS |
